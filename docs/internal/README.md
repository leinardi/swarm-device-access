# Internal documentation

Pages for the maintainers of this repository. They are excluded from the documentation site, but
they are public on GitHub like everything else here, so nothing secret belongs in them.

- [`release.md`](release.md): how a release is versioned, built, published and recovered, and the
  one-time repository setup it relies on.
- [`rust-port.md`](rust-port.md): the design and provenance record of the Rust port, with the
  reuse ledger.
- [`history/`](history/): finished records, kept as written. It holds the
  [Go 1.x release notes](history/go-releases.md).
- [`qa/`](qa/): test-run records. It holds the [Go-to-Rust field test](qa/field-test.md).
- [`restructure/`](restructure/): the record of the documentation restructure: the report, the
  approved plan, the content mappings and their review receipts.
