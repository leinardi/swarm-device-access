# Historical notes: the Go releases (1.x)

> **Status:** Historical: the Go 1.x release notes, split from the release runbook in November 2026.
> The current process is in docs/internal/release.md.

Releases up to and including `v1.0.3` were built from the Go implementation, which the 2.0 cutover
replaced ([`docs/internal/rust-port.md`](../rust-port.md)). A recovery of a 1.x release runs on that
release's commit, whose workflows still describe how it was built, so nothing here is needed to run
one.
